# Live Notes (working title)

An AI that listens to a lecture and writes the notes for you — live. It drafts concise notes, draws diagrams, highlights the lecturer's slides as they talk, revises itself when the lecturer corrects something, and afterwards replays audio, slides and notes in sync.

- Plan and roadmap: [`docs/PLAN.md`](docs/PLAN.md)
- Research: [`docs/research/`](docs/research)
- Protocol (the contract between every part of the system): [`packages/protocol`](packages/protocol)

Status: Phase 0 — de-risking the core loop on scripted sessions. Nothing here is production-ready.
